# 🧠 Multiple Choice Quiz App

A Streamlit web app that lets users take a multiple-choice quiz and get instant scoring and feedback.

Features

Take a 10-question (or more) quiz.

Select answers via radio buttons.

Get instant score after submitting.

Review which answers were correct or incorrect.

Fun interactive features like Streamlit balloons for a perfect score.

Installation

Clone the repository:

git clone https://github.com/<your-username>/multiple-choice-quiz.git
cd multiple-choice-quiz


Install dependencies:

pip install streamlit

Usage

Run the app locally:

streamlit run quiz_app.py


Answer all questions by selecting one option per question.

Click Submit Quiz to see your score and review answers.

Celebrate a perfect score with balloons animation!
